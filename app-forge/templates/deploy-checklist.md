# Deployment Checklist

## Pre-deploy
- [ ] All tests passing
- [ ] TypeScript clean
- [ ] Env vars documented
- [ ] DB migrations ready

## Deploy
- [ ] Push to main
- [ ] CI/CD passes
- [ ] Staging verified

## Post-deploy
- [ ] Health check responding
- [ ] Error monitoring active (Sentry)
- [ ] Performance monitoring active
- [ ] Alerts configured

## Rollback
- [ ] Previous deploy tagged
- [ ] Migration rollback scripts ready
