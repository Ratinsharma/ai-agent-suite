# Incident Response Playbook

## Severity Levels
- SEV1: Customer outage (15 min response)
- SEV2: Degraded performance (1 hour)
- SEV3: Non-critical failure (4 hours)
- SEV4: Cosmetic (24 hours)

## Response Steps
1. Detect (alert or user report)
2. Triage (assess severity, notify team)
3. Mitigate (restore: rollback, failover, scale)
4. Investigate (root cause)
5. Resolve (fix underlying issue)
6. Review (postmortem, skillify learnings)

## Postmortem
- What happened?
- When did it start?
- Impact? (users, revenue, duration)
- Root cause?
- What prevents recurrence?
- What was skillified?
