## Rules
- Don't copy-paste — adapt format for each channel
- Lead with the hook from the original (first 3 seconds / first line)
- Add platform-specific elements (hashtags for IG, threads for X, carousels for LinkedIn)
- Track which repurpose formats drive the most engagement → double down
