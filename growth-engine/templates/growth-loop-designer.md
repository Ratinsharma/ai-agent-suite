# Growth Loop Designer

> Growth loops compound: output feeds back as input. Design them intentionally.

## Loop template

### Loop name: <NAME>
**Trigger:** <what starts the loop>
**Action:** <what the user/agent does>
**Output:** <what gets created>
**Feed-back:** <how output becomes input for the next cycle>

### Example: Content → Community → Customers
1. **Trigger:** Publish a valuable blog post / thread
2. **Action:** Reader shares it with their network
3. **Output:** New audience members discover you
4. **Feed-back:** Some join your community → some become customers → some create content about you → feeds back to step 1

### Example: Product → Usage → Word-of-Mouth
1. **Trigger:** Customer uses product successfully
2. **Action:** Customer tells a colleague / posts about it
3. **Output:** Referral traffic
4. **Feed-back:** New customer → uses product → tells others → feeds back to step 1

## Anti-patterns
- Loops that require constant paid input (not self-sustaining)
- Loops with no feed-back mechanism (one-and-done)
- Loops that depend on viral mechanics (unreliable)
- Loops that don't measure the feed-back step
