# Contributing

Thanks for improving the AI Agent Suite.

## Guidelines

- Keep each agent self-contained under its folder (`SKILL.md` + `templates/`).
- Do not invent APIs, tools, or product claims that are not already in the playbooks.
- Prefer concrete numbers, scripts, and checklists over vague advice.
- Match existing Markdown tone and section structure.
- Open a PR with a clear summary of what changed and why.

## Pull requests

1. Fork / branch from `master`.
2. Edit only the agent docs you intend to change.
3. Fill out the PR template.
4. Link related issues when applicable.
